# Exemplos Padrão Ouro

Entregas reais e excelentes, usadas pelos subagentes como **régua de profundidade e especificidade**. Elas nunca servem de conteúdo para copiar.

## Como adicionar um exemplo

1. Escolha a melhor entrega já aprovada de uma etapa. Ela deve ter nota 5 na rubrica e o Estrategista deve ter se orgulhado dela.
2. Salve como `NN_<nome>_exemplo.md`, por exemplo `09_personas_exemplo.md`. O subagente da etapa NN encontra o arquivo pelo prefixo `NN_`.
3. **Anonimize:** troque nomes de pacientes, valores de faturamento e dados pessoais. Mantenha o nível de detalhe, as frases literais de público e a estrutura.
4. No topo, escreva 3 linhas explicando **o que torna este exemplo excelente**. É isso que o agente vai imitar.
